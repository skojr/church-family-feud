Send to

The IP of each computer that should receive cues, and the port its app listens on. Use 127.0.0.1 for an app on this computer. Common ports: QLab 53000, Resolume 7000, Companion 12321, ETC Eos 8000 (set in the desk's network settings).

Cues

  1. In your lighting program, put the OSC input in learn mode for the button or cue you want.
  2. Press Send next to the moment below. The program picks up that address.
  3. Done. During the game the same message goes out every time that moment happens.

Prefix

If your program learns the address but doesn't react during the game, try Just 1.0. Changing the prefix changes every address, so learn them again afterwards.

Typing an address instead

If a program needs a specific address (it doesn't learn), use + Type an address on a moment. Values: 1 whole number, 1.0 decimal, true/false, 'quoted text'. Click a {placeholder} to put in the live value.

  • ETC Eos / Ion: fire a cueAddress /eos/cue/1/5/fire · no values
  • ETC Eos: different cue per answer slotAddress /eos/cue/2/{slot}/fire on “Correct answer revealed”
  • grandMA3: run a commandAddress /gma3/cmd · values 'Go+ Sequence 5'
  • QLab: start a cueAddress /cue/STRIKE/start · no values
  • Companion: press a buttonAddress /location/1/0/3/press · no values

Desks differ: check your desk's OSC manual for its exact addresses.

Built-in cues

Built-in cues (/feud/strike/2, /feud/buzz/A …) carry values for apps like Companion and TouchDesigner, and are listed in the buzzer-hub README. Turn them off if you only use the moment cues, so nothing else arrives while a program is learning.
